# Bhavana Biradar — Developer Portfolio

A responsive dark-themed personal portfolio built with React, Vite, CSS, and Lucide icons.

## Run locally

1. Install Node.js (LTS) if it is not already installed: https://nodejs.org/
2. Open Terminal in this folder.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Before publishing

- Check every project description and replace any wording that does not match your actual contribution.
- Verify the RealityOS and MochaTrade repository URLs.
- Add the actual repository or demo URL for Smart Blind Stick and the SIH project if available.
- Add a professional photo only if you want one; the current design intentionally uses a code-themed visual instead.
- Keep secrets, API keys, `.env` files, and credentials out of the repository.
- Deploy the site with a static hosting service such as GitHub Pages, Netlify, or Vercel.
